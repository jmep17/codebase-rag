Design principles

  • Local-first is a feature, not fine print. A persistent shield indicator shows what's leaving the machine.
  • Retrieval is visible by default. Every assistant turn carries the chunks that grounded it, with scores and sources.
  • Every destructive action is reviewable. Writes, edits, and shell commands surface as cards with approve / reject / edit.
  • The audit log is a first-class view, not a debug aid — the receipt for everything the agent did.
  • One mental model across surfaces. Same slash commands, same colors, same components in TUI, browser, and desktop.
  • Keyboard-first everywhere. ⌘K palette, slash commands, j/k navigation — mouse works but isn't required.
